# CVRBOY — Issue System Shopify Theme

Custom Shopify Online Store 2.0 rebuild for **CVRBOY**.

## Brand direction

- **CVRBOY**
- **Cover What You Love.**
- **Nerd Utility**
- **Culture Covers Everything.**
- **Small Guy. Big Ideas.**
- Product drops are organized as **Issues**, not seasons.

The visual system is fashion-first, reference-second: editorial spacing, black/cream/stone/signal-red, issue numbering, manga/print cues, and the CVRBOY mascot used as a recurring secondary brand asset rather than novelty decoration.

## Included storefront system

- Sticky minimal navigation
- Issue-based homepage hero
- Shopify-powered featured product grid
- Issue archive cards
- Mascot/character storytelling section
- Brand manifesto
- Product detail template with source-material language
- Collection template
- Cart drawer + full cart page
- Search
- Story page template
- Lookbook page template
- 404/default pages
- Theme editor settings for core brand colors

## Shopify setup

1. Connect/upload this repository as a Shopify theme.
2. Create pages with handles **story** and **lookbook**.
3. Assign `page.story` and `page.lookbook` templates.
4. In the theme editor, connect the real CVRBOY collection to **Featured products**.
5. Add final Issue 001 campaign photography and lookbook images.
6. Optional: create a product metafield `cvrboy.issue` to display issue numbers on product cards and PDPs.
7. Upload the finalized CVRBOY logo asset in the Header settings.
